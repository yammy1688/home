Statistics — Data, Plots & Measures / 統計學

📖 8.1 — Measures of Central Tendency

Three numbers can summarize a whole data set: mean (average), median (middle), mode (most common). Pick the one that tells the clearest story about your data.

Key Formulas / 關鍵公式

Mean 平均數

mean = Σx ÷ n
Sum of values ÷ count

Median 中位數

middle value (sorted)
Even n → average of two middles

Mode 眾數

most frequent value
Can have 0, 1, or many modes

Range 全距

max − min
How spread out the data is

Outlier 離群值

value far from the rest
Pulls the mean; median is safer

Which to Use 怎麼選

skewed → median
Symmetric → mean works fine
📊
Example 1: Finding the Mean / 求平均數
MEAN / 平均數
1
Given / 已知
Kayla’s quiz scores: 82, 90, 75, 88, 95. Find the mean.
2
Add all values / 加起來
Σx = 82 + 90 + 75 + 88 + 95 = 430
3
Divide by count / 除以個數
n = 5,  mean = 430 ÷ 5 = 86
💡 Pro Tip
Mean is the “balance point” of the data. One very high or very low value can tilt it way off — that’s when the median becomes a better story. / 平均數容易被極端值拉走。
🎯
Example 2: Median — Odd vs Even / 中位數奇偶
MEDIAN / 中位數
1
Sort first! / 先排序
Data A (odd): 7, 3, 9, 5, 1 → sorted: 1, 3, 5, 7, 9.
Data B (even): 4, 8, 2, 6 → sorted: 2, 4, 6, 8.
2
Odd count = pick the middle / 奇數取中間
MedianA = 5 (the 3rd of 5)
3
Even count = average the two middles / 偶數取平均
MedianB = (4 + 6) ÷ 2 = 5
💡 Pro Tip
Always sort before finding the median. Forgetting this is the #1 mistake on tests. / 找中位數前一定要先排序！
🎲
Example 3: Mode — The Most Frequent / 眾數
MODE / 眾數
1
Count how many times each value appears / 數每個值的次數
Data: 3, 7, 5, 3, 9, 7, 3, 5.
Tally: 3 → 3 times, 5 → 2, 7 → 2, 9 → 1.
2
Pick the highest count / 最高次數
Mode = 3 (appears 3 times)
3
Multi-mode or no mode / 雙眾數或無眾數
If two values tie for the top count, there are two modes (bimodal). If every value appears once, there’s no mode.
💡 Pro Tip
Mode is the only measure that works for non-numeric data too — e.g., the most common eye color in a class. / 眾數是唯一可用於非數字資料的量數。
⚠️
Example 4: Outlier Effect / 離群值的影響
MEAN vs MEDIAN / 平均與中位
1
Data / 資料
Salaries ($1000s): 30, 32, 35, 36, 40, 42, 300 (last is the boss).
2
Mean gets pulled up / 平均被拉高
mean = 515 ÷ 7 ≈ 73.6
Nobody except the boss earns that much.
3
Median stays realistic / 中位數較真實
sorted middle (4th of 7) = 36
Median ignores how extreme the outlier is.
💡 When to Pick
If the data is skewed or has outliers, the median summarizes the “typical” value better. For roughly symmetric data, the mean is fine. / 資料偏斜用中位數，對稱用平均數。

🌳 8.2 — Stem-and-Leaf & Dot Plots

Two quick ways to picture small data sets. Stem-leaf keeps every original value; dot plots stack a dot per value over a number line.

Key Ideas / 關鍵概念

Stem | Leaf 莖 | 葉

stem = tens, leaf = ones
e.g. 47 → stem 4, leaf 7

Key 圖例

4 | 7 means 47
Always include a key!

Sorted Leaves 排序

smallest → largest
Within each stem row

Dot Plot 點圖

• per data point
Stacked over the value

Reading Shape 判斷分佈

peak, cluster, gap
Find mode, spread visually

Good For 適用情境

small sets (< 50)
Big data → use a histogram
🎯
Example 1: Build a Stem-and-Leaf Plot / 製作莖葉圖
CONSTRUCTION / 製圖
1
Raw data / 原始資料
Test scores: 72, 79, 91, 78, 85, 67, 94, 72, 83, 79, 85, 85.
2
Split each number into stem & leaf / 拆成莖與葉
72 → 7 | 2, 85 → 8 | 5, 91 → 9 | 1, …
3
Group by stem, sort leaves / 依莖分組、葉排序
6 | 7
7 | 2 2 8 9 9
8 | 3 5 5 5
9 | 1 4
Key: 6 | 7 means 67.
4
Read info straight off the plot / 直接讀出資訊
Mode = 85 (appears 3 times). Most scores cluster in the 70s & 80s.
💡 Pro Tip
The leaves keep the original data — you can always reconstruct every score. Histograms and dot plots lose that detail. / 莖葉圖保留原始資料。
🔍
Example 2: Median from a Stem-Leaf / 從莖葉找中位數
READING / 讀圖
1
Plot / 圖
6 | 7
7 | 2 2 8 9 9
8 | 3 5 5 5
9 | 1 4
2
Count total values / 總個數
n = 1 + 5 + 4 + 2 = 12 (even).
3
Middle two values / 中間兩個
The 6th & 7th values when sorted are 79 and 83.
4
Average them / 取平均
median = (79 + 83) ÷ 2 = 81
💡 Pro Tip
Since the leaves are already sorted within each stem, finding the median is just counting. / 葉已排序，找中位數只需計數。
🔵
Example 3: Dot Plot / 點圖
CONSTRUCTION / 製圖
1
Data / 資料
Number of pets: 0, 1, 2, 1, 3, 2, 1, 0, 4, 1.
2
Draw a number line / 畫數線
Range from 0 to 4. For each value, stack one dot above its position.
3
Dot counts / 點數統計
0 → 2, 1 → 4, 2 → 2, 3 → 1, 4 → 1. Total = 10. Tallest column = 1 pet (the mode).
💡 Pro Tip
The tallest stack is always the mode; a wide spread of stacks → more variation. / 最高的一疊就是眾數。

📊 8.3 — Frequency Tables & Histograms

When data has lots of values, group them into class intervals and count how many fall in each. A histogram is a bar chart of those counts — no gaps between bars.

Key Ideas / 關鍵概念

Class Interval 組距

equal width groups
e.g. 10–19, 20–29, …

Frequency 頻率

count per interval
Tally marks → numbers

Histogram 直方圖

bars touch (no gaps)
Because data is continuous

Bar Chart 長條圖

bars have gaps
Categorical data (words)

Modal Class 眾數組

tallest bar
Interval with most values

Relative Frequency 相對頻率

freq ÷ total
Expressed as % or fraction
📋
Example 1: Build a Frequency Table / 製作頻率表
TALLY / 劃記
1
Data / 資料
Heights (cm): 142, 151, 138, 160, 155, 147, 133, 168, 159, 144, 152, 146, 139, 162, 150.
2
Choose equal intervals / 選擇組距
Min 133, Max 168 → use 10-cm groups: 130–139, 140–149, 150–159, 160–169.
3
Tally each value / 劃記
130–139: 3
140–149: 4
150–159: 5
160–169: 3
Check: 3 + 4 + 5 + 3 = 15 ✓
4
Modal class / 眾數組
Tallest bar → 150–159 cm (5 students).
💡 Pro Tip
Use 5–10 intervals of equal width. Fewer → loses detail; more → bars too thin. / 5 到 10 組剛剛好。
📊
Example 2: Draw the Histogram / 畫直方圖
GRAPHING / 繪圖
1
Axes / 座標軸
x-axis: class intervals. y-axis: frequency (count). Label both!
2
Bars touch / 長條相鄰
No gaps between bars — data is continuous.
3
Bar heights / 長條高度
Match each interval’s frequency. Tallest bar = modal class.
💡 Bar vs Histogram
Bar chart bars have gaps (categories). Histogram bars touch (continuous). / 長條圖有空隙，直方圖相鄰。
🔎
Example 3: Interpret the Histogram / 解讀直方圖
READING / 讀圖
1
Scenario / 情境
A histogram of daily steps shows intervals 0–2k, 2–4k, 4–6k, 6–8k, 8–10k with frequencies 2, 5, 8, 6, 4 (total = 25 people).
2
How many walked ≥ 6k steps? / 六千步以上？
6 + 4 = 10 people
3
Fraction ≥ 6k / 佔比
10 ÷ 25 = 40%
4
Modal class / 眾數組
Tallest bar = 4–6k steps (frequency 8).
💡 Pro Tip
You can’t recover exact values from a histogram — only counts per interval. That’s the trade-off for handling big data. / 直方圖看不到個別資料。
